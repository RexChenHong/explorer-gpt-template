# Explorer GPT 模板（開源專案低成本探索流程）

> 一套幫助「沒有資工背景、看不懂英文技術文件」的人，  
> 以 **低 token 成本、多模型協作** 的方式探索大型 GitHub 開源專案的流程模板。

---

## 這是什麼？

這個 repo 放的是一套 **「方法論模板」**，不是程式庫。

它教你如何：

- 從一個 GitHub 開源專案網址開始
- 先用終端機指令在本機「看結構、做篩選」（不花 token）
- 再用 **便宜模型（低階模型）** 做「廣、淺」的設計模式／習慣萃取
- 最後才用 **高階模型** 在「萃取出來的摘要」上做深度思考與裁決  
  （而不是讓高階模型直接讀整個 repo 燒爆 token）
- 把真的有價值的結論，變成你自己的 **agent skills / 系統規範**

這套流程特別適合：

- 沒有資工背景、也不熟英文技術文件的人
- 想從大型開源專案（例如 Polars、vn.py 等）學「工程思維」，  
  而不是單純複製程式碼的人
- 個人量化交易系統開發者，重視 **效能、穩定性、長時間運行**

這是一個 **一次性快照**（snapshot），並不打算長期維護更新。

## 專案結構

```text
explorer-gpt-template/
├── README.md                    # 英文簡介
├── README_zh-TW.md              # 本檔（繁體中文簡介）
├── EXPLORER_GPT.md              # 核心方法論：Explorer GPT 工作流程
├── LICENSE                      # MIT 授權
└── examples/
    ├── polars_low_tier_extraction.md
    └── polars_high_tier_evaluation.md
EXPLORER_GPT.md
```

核心文件，定義：

角色分工（你、終端機工具、低階模型、高階模型）

階段流程（Phase 1 ~ Phase N）

每一階段可以做什麼、不可以做什麼

可直接複製貼上的 Prompt 模板

examples/polars_low_tier_extraction.md
以 Polars 開源專案為例，展示 低階模型探索的實際輸出長相。
讓你知道「一份品質良好的萃取結果大概會包含哪些內容」。

examples/polars_high_tier_evaluation.md
延續同一個 Polars 例子，展示 高階模型如何在萃取摘要上做判斷與裁決，
最後產生可直接用於你自己系統的「設計規範 / 原則」。

這個專案「不是」什麼？

本專案 不是：

Polars 或其他專案的教學課程

任何形式的程式庫、框架或工具包

交易策略範例或實盤建議

對「最佳實作」的保證

它是：

一個「和 LLM 溝通的腳本」
一份「低成本探索開源專案的對話劇本」

如何使用這個模板？

先讀 EXPLORER_GPT.md

理解整體流程與規則

理解每個階段你該做什麼、模型該做什麼

對照 examples/polars_*.md

把它們當成「範例產物」

用來校準：

低階模型輸出的大概範圍與深度

高階模型該專注在哪些決策問題

將流程套用到你自己的目標 repo

從 GitHub 開源包網址開始

用 EXPLORER_GPT.md 的流程一步一步走

不要讓高階模型直接讀整個 repo，而是只看「萃取後的摘要」

如果你覺得某些結論很有價值

可以進一步整理成你自己的
agent skills / 系統運行規範 / code review 準則。

範圍與免責聲明

這是某次實際探索流程的快照，不會隨開源專案版本變動而更新。

範例中的 Polars 相關觀察，只是示範如何萃取設計思維，
並非 Polars 官方觀點。

如何將這些想法應用到真實系統，需由使用者自行評估風險。
